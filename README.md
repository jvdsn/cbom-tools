# CBOM Tools

A collection of tools to generate, refine, or analyze CBOMs in the context of compliance evaluations

## CAVP to CBOM

Converts CAVP certificates to CBOMs in CycloneDX 1.7 format.

## CBOM Compliance

Analyze CBOM for compliance against various standard profiles:
- CNSA 1.0
- NIAP Policy Letter #5 Addendum 2
- CNSA 2.0
- CNSA 2.0 strict (no SHA-3)
- ENISA Agreed Cryptographic Mechanisms Version 2.0
- ENISA (post-quantum) Agreed Cryptographic Mechanisms Version 2.0

## Refine CBOM

LLM-assisted refinement of CBOMs using a NIAP Security Target.
